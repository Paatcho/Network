RENDU DEVOIR FINAL
Basé sur le précédent rendu "cristal"

Scène de démonstration dans la scène Rendu. Elle affiche des cristaux de glace de différentes couleurs.
Des objets de couleurs unies sont disposés pour montrer l'effet de reflet/réfraction.

Ajout de 4 nouvelles fonctionnalités HLSL :
- Effet de glow qui oscille (Shader/Glow.hlsl)
- Effet de sparkles (Shader/Sparkles.hlsl)
- Bonus : Outline (ne fonctionnait pas avec les cristaux donc est juste placé sur une sphère)
  -> est dans un shadergraph différent (Shader/Outline)
- Bonus : Facet (effet de réfraction supplémentaire, fonctionne mieux comme régulateur de "roughness")
